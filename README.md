# OneNote-Style Note Tool
仿 OneNote 本地笔记工具，纯前端实现，基于浏览器 File System Access API 读写本地文件，无需后端、无需数据库，笔记永久存在你的电脑本地。

## 📖 项目简介
本项目复刻微软 OneNote 经典三层侧边栏结构：**笔记本 → 分区 → 页面**，完整还原 OneNote 目录管理逻辑，提供富文本编辑器，所有笔记以 Markdown 文件存储在你自选本地文件夹，数据完全由自己掌控。

### 核心设计（对标 OneNote）
1. 左侧一级栏：笔记本列表（对应 OneNote 笔记本导航）
2. 顶部标签栏：彩色分区 Section（对应 OneNote 彩色分区标签）
3. 左侧二级栏：页面列表（对应 OneNote 页面侧边栏）
4. 中间画布：无边距富文本编辑区域，支持格式化、列表、标题等

## ✨ 功能特性
### 1. 三层层级管理（OneNote 同款结构）
- 笔记本：本地一级文件夹，可新建、删除、重命名
- 分区 Section：笔记本内二级文件夹，自带随机彩色标识，横向标签展示
- 页面 Page：`.md` 文件存储，支持标题、富文本内容，自动记录创建/更新时间

### 2. 富文本编辑工具栏
- 撤销 / 重做
- 文字样式：加粗、斜体、下划线、删除线
- 标题层级：H1 / H2 / H3 / 正文段落
- 列表：有序列表、无序列表、缩进增减

### 3. 文件存储机制（本地优先，无云端）
- 使用浏览器 File System Access API 读写本地文件夹
- 文件结构映射：
  ```
  你选择的根文件夹/
  ├─ 笔记本A/          # 笔记本
  │  ├─ _meta_.json    # 分区创建时间元数据
  │  ├─ 分区1/         # Section 分区
  │  │  ├─ _meta_.json
  │  │  └─ 欢迎页面.md  # 笔记页面（YAML头存储标题、时间）
  │  └─ 分区2/
  └─ 笔记本B/
  ```
- Markdown 文件内置 YAML FrontMatter，保存页面标题、创建时间、更新时间
- 自动防抖保存，Ctrl+S 手动强制保存

### 4. 实用工具能力
- 全局搜索：检索所有笔记本、分区、页面标题与正文内容，自动高亮匹配文字
- 右键菜单：笔记本/分区/页面支持重命名、删除
- 弹窗新建：一键创建笔记本、分区、页面
- 操作 Toast 提示，删除二次确认防止误操作
- 页面按更新时间倒序展示，快速找到最近笔记
- 完整 HTML 转义防护，防止 XSS

### 5. 快捷键
| 快捷键 | 功能 |
|--------|------|
| Ctrl/Cmd + S | 手动保存当前页面 |
| Ctrl/Cmd + B | 加粗文字 |
| Ctrl/Cmd + I | 斜体文字 |
| Ctrl/Cmd + U | 下划线 |
| Ctrl/Cmd + N | 新建页面 |

## 🖥 运行环境要求
> 依赖 `showDirectoryPicker` 文件系统 API，仅支持 Chromium 内核浏览器
- ✅ 推荐：Google Chrome 86+、Microsoft Edge 86+
- ❌ 不支持：Firefox、Safari、移动端浏览器

## 🚀 快速使用
1. 克隆仓库到本地
```bash
git clone https://github.com/你的用户名/one-note-clone.git
cd one-note-clone
```
2. 直接打开项目内 `index.html` 文件（无需本地服务，双击即可）
3. 首次打开会弹出文件夹选择框：
   - 点击「选择文件夹」，新建一个空白文件夹作为笔记根目录
4. 工具自动生成默认笔记本、分区与欢迎页面，直接开始写笔记

## ⚠️ 重要注意事项
1. **浏览器权限**
   刷新页面后，浏览器会重新请求文件夹读写权限，允许即可恢复笔记；拒绝则需重新选择文件夹。
2. **数据安全**
   所有笔记仅保存在你本地文件夹，不上传任何服务器；删除笔记本/分区/页面会直接删除本地文件，**不可恢复**，删除前请确认。
3. **文件名限制**
   新建名称会自动过滤 Windows/Mac 非法字符（`< > : " / \ | ? *`），自动替换为下划线。
4. 兼容性限制
   Firefox / Safari 未实现 File System Access API，无法读写本地文件夹，页面会提示更换浏览器。

## 📝 数据格式说明
每个页面 `.md` 文件标准格式：
```markdown
---
title: 页面标题
created: 2026-07-28T10:00:00.000Z
updated: 2026-07-28T15:30:00.000Z
---

<h2>笔记正文富文本内容</h2>
<p>支持HTML格式存储排版</p>
```
